下载应用

选择你的系统，开始使用

无需准备开发环境。所有安装包由 GitHub Actions 构建，并随版本发布到 GitHub Releases。

Windows

Windows x64

下载安装 EXE 或 MSI，运行安装程序即可。

选择 Windows 安装包 ↗EXE · MSI
macOS

Apple Silicon / Intel

按处理器选择 DMG，打开后拖入“应用程序”。

选择 macOS 安装包 ↗DMG · ARM64 / x64
Linux

Linux x64

选择通用 AppImage，或用于 Debian/Ubuntu 的 DEB。

选择 Linux 安装包 ↗AppImage · DEB

若尚无正式版本，可从 最新构建记录下载临时安装包。

核心能力

从编辑到回溯，一处完成

01

双视图编辑

表单方便日常维护；源码视图保留对原始 JSON 或 XML 的直接控制。

02

Schema 驱动

通过分组、字段校验和条件展示组织表单。没有 Schema 时，也能从现有内容推导表单。

03

版本与备份

保存前备份旧文件，记录配置与 Schema 版本；历史内容可先加载到编辑区，再决定是否保存。

04

本地文件优先

直接使用你的配置目录，支持 JSON、XML 与配套 Schema；后端校验访问路径并采用原子写入。

开始使用

打开程序，选好配置目录

首次启动时应用会准备一份可编辑的示例配置。你也可以随时切换到自己的 JSON 或 XML 配置目录。

  1. 安装并打开下载与你的系统、处理器匹配的安装包。
  2. 选择配置目录保留示例目录，或点击“浏览…”选择自己的目录。
  3. 编辑并保存选择表单或源码视图；保存前会备份旧文件。
一次保存，保留来路
01读取配置JSON / XML
02编辑内容表单 / 源码
03保存版本自动备份

历史内容可先加载回编辑区，再由你决定是否保存。

现有配置也能用

直接选择你的配置目录

把 JSON 或 XML 文件放在同一目录即可加载。需要更明确的字段分组和校验时，可以在 schemas/ 中加入对应的 Schema。
